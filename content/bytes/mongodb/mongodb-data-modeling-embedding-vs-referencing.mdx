## Quick Start
Atlas Vector Search compares a question embedding with stored embeddings. It ranks documents by semantic similarity, while metadata filters keep retrieval inside the correct product, language and access boundary.

<MongoDBConceptLab variant="vector" />

## Start from Basics
An embedding is a numeric representation of meaning. “How much can I send by UPI?” can retrieve “Daily transfer limits” even without exact keyword overlap.

## Core Explanation
Store original text, embedding, source identity and governance metadata together. A vector is not evidence by itself; the application supplies the retrieved text and source to the model.

```javascript
{ chunk_id: "policy_12_03", text: "The daily UPI transfer limit is ₹1,00,000...",
  embedding: [0.021, -0.184, 0.336], product: "upi", language: "en",
  access: ["customer"] }
```

## Types and Components
1. Chunk approved source content.

3. Store text, vectors and metadata.
4. Create a Vector Search index.
5. Embed the question, filter and rank evidence.

## Vector Search vs Keyword Search
| Capability | Keyword | Vector |
|---|---|---|
| Exact terms | Strong | Indirect |
| Paraphrases | Limited | Strong |
| Best pattern | Lexical signals | Semantic signals plus filters |

## Real-World Examples
A support assistant searches only active UPI policies available to customers in the selected language. The model receives top passages with document IDs and produces a cited answer.

## Common Mistakes
<Mistakes>

- Mixing incompatible embedding models or dimensions.
- Returning relevant but unauthorised documents.
- Sending vectors instead of text to the model.
- Treating top-one retrieval as automatically correct.

</Mistakes>

## Key Takeaways
<Takeaways>

- Embeddings represent meaning numerically.
- Stored and query vectors need the same space.
- Vector indexes differ from field indexes.
- Source text and metadata remain essential.
- Filters enforce business boundaries.
- Ranking does not guarantee correctness.
- Hybrid retrieval combines useful signals.
- Evaluate retrieval before generation.

</Takeaways>

## FAQ, Knowledge Check and Interview Answer
**Can Vector Search replace all indexes?** No. It uses a specialised index; application filters and sorting may need standard indexes.

**Interview answer:** Atlas Vector Search lets an application store content, embeddings and metadata together and retrieve semantically similar evidence with governance filters.
