## Quick Start
An aggregation pipeline passes documents through ordered stages. Each stage performs one transformation—filtering, grouping, reshaping or sorting.

<MongoDBConceptLab variant="aggregation" />

## Start from Basics
`$match` filters, `$group` summarises, `$project` reshapes and `$sort` orders. Stage order matters: filtering early reduces later work.

## Core Explanation
```javascript
db.learning_events.aggregate([
  { $match: { event: "lesson_completed" } },
  { $group: { _id: "$learner_id", completed: { $sum: 1 }, last_at: { $max: "$created_at" } } },
  { $project: { _id: 0, learner_id: "$_id", completed: 1, last_at: 1 } },
  { $sort: { completed: -1 } }
])
```

## Types and Components
- `$match` narrows documents.
- `$unwind` expands array items.
- `$group` calculates totals and latest values.
- `$project` creates the final contract.
- `$setWindowFields` adds rankings or rolling values.

## Pipeline vs Application Loop
| Approach | Strength | Risk |
|---|---|---|
| Aggregation | Near-data, repeatable stages | Hard to read if monolithic |
| Application loop | Familiar code | More transfer and duplicated logic |
| Materialised summary | Fast repeated reads | Needs freshness strategy |

## Common Mistakes
<Mistakes>

- Grouping before filtering.
- Returning unnecessary internal fields.
- Building training features with future data.
- Hiding decisions inside an unreadable pipeline.

</Mistakes>

## Key Takeaways
<Takeaways>

- Pipelines transform data stage by stage.
- Stage order changes cost and meaning.
- Filter early when possible.
- Group at the business grain.
- Project a stable output.
- Inspect intermediate results.
- Protect time cut-offs for ML.
- Test realistic data volumes.

</Takeaways>

## FAQ, Knowledge Check and Interview Answer
**Why not calculate everything in application code?** Pipelines often reduce data transfer and centralise repeatable logic.

**Interview answer:** MongoDB aggregation is an ordered transformation pipeline. I filter early, group at the required grain and project a stable output.
