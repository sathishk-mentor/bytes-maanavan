## Why Python still matters in the AI era

AI can generate code, but an application still needs a language to validate data, call models, connect tools, enforce permissions and test results. Python is widely used for these jobs because its syntax is readable and its ecosystem covers APIs, data, machine learning and automation.

Your goal is not to memorise every Python feature. Learn enough to **read, question, run, test and improve** the code that powers an AI workflow.

## Set up a safe workspace

Install a current supported Python release and VS Code. Create one project folder and isolate its packages:

```bash
python -m venv .venv
# Activate .venv, then:
python -m pip install --upgrade pip
```

A virtual environment is like keeping each course’s lab materials in a separate box. One project can upgrade a package without unexpectedly changing another project.

## Values and data structures

```python
learner_name = "Kavin"                   # string
study_hours = 6                           # integer
is_beginner = True                        # Boolean
interests = ["Python", "AI Agents"]      # list: ordered and changeable
profile = {"goal": "AI Engineer"}        # dictionary: key and value
levels = ("beginner", "intermediate")    # tuple: fixed sequence
completed = {"SQL", "Git"}               # set: unique values
```

Choose a structure from the behaviour you need. A dictionary fits a learner profile because each value has a meaningful key. A list fits a learning path because order matters.

## Conditions, loops and functions

```python
def recommend_course(skill_level: str, interest: str) -> str:
    if skill_level == "beginner" and interest == "AI":
        return "Start with Python and Generative AI"
    return "Explore the complete course library"

recommendation = recommend_course("beginner", "AI")
print(recommendation)
```

The type hints explain the intended contract. They improve readability and tooling, but Python does not automatically enforce every type at runtime.

## Read errors as evidence

When code fails, start at the final exception line, then inspect the referenced file and line number. Reproduce the error with the smallest input before changing code.

```python
try:
    weekly_hours = int(input("Weekly study hours: "))
except ValueError:
    print("Enter a whole number, such as 5")
```

Do not hide every exception with a broad `except`. Handle failures you understand and let unexpected failures remain visible during development.

## Use AI coding assistants responsibly

- Ask for an explanation before accepting unfamiliar code.
- Give the assistant the goal, input format and expected examples.
- Run the code in an isolated development environment.
- Test normal, empty and invalid inputs.
- Never paste passwords, API keys or private learner records.
- Keep human ownership of dependencies and final behaviour.
