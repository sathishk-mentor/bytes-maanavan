## Build the Task Manager step by step

**Our learning project:** A tiny Task Manager, not an enterprise support system. The app grows gradually across the five Bytes; each code step below tells you exactly which file to edit.

**Milestone 2:** React Components and Props: Display Reusable Task Cards.

### Step 1: Create a typed reusable component

**Where:** `src/components/TaskItem.tsx`

```tsx
export type Task = { id: number; title: string };
export default function TaskItem({ title }: { title: string }) {
  return <li>{title}</li>;
}
```

**Expected screen/result:** A component is ready to receive a title prop.

### Step 2: Create task data

**Where:** `src/data/tasks.ts`

```tsx
import type { Task } from '../components/TaskItem';

export const initialTasks: Task[] = [
  { id: 1, title: 'Read React notes' },
  { id: 2, title: 'Practise JSX' }
];
```

**Expected screen/result:** Tasks are separate from the UI; each has a stable id.

### Step 3: Update App to render components

**Where:** `src/App.tsx`

```tsx
import TaskItem from './components/TaskItem';
import { initialTasks } from './data/tasks';

export default function App() {
  return (
    <main>
      <h1>My Task Manager</h1>
      <ul>
        {initialTasks.map(task => (
          <TaskItem key={task.id} title={task.title} />
        ))}
      </ul>
    </main>
  );
}
```

**Expected screen/result:** Both tasks appear, this time through the same reusable component.

**Project checkpoint:** Reusable task cards.

## Common mistakes and how to avoid them

Do not mutate props in a child component. Avoid array indexes as keys for lists that can change order. A component named taskItem in JSX would be treated like a native element; use PascalCase.

When something breaks, read the first error message, identify the file involved, and compare your code against the prior working checkpoint.

## FAQ and knowledge check

- Why a key? It helps React track list item identity.
- Why props? One component can display different inputs.
- Can the child change the parent's prop? Treat props as read-only.
