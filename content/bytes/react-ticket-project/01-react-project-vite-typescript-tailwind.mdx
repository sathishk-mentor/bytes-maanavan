## What you will build

**Milestone 11:** Start with a completely empty project. We will create the Support Desk shell before introducing tickets, state or APIs. The important outcome is a page you can run and understand, not an unexplained collection of packages.

A project needs a repeatable setup and clear folder structure before adding features.

**Visible checkpoint:** The app shows a clean Support Desk heading and description. You can study this Byte by itself, though the project can also be built progressively.

## Understand the concept first

Vite runs and builds a React project. TypeScript checks types during development; Tailwind provides utility CSS classes. Create a small application shell before adding ticket features.

In plain language, an interface should show useful information and respond predictably to users. We begin with one small technical change before introducing more features.

### Step 2 — Configure Tailwind in Vite

**Edit or create the indicated file.**

```tsx
// vite.config.ts
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import tailwindcss from '@tailwindcss/vite';
export default defineConfig({plugins:[react(),tailwindcss()]});
```

## Key Takeaways

1. Vite creates a practical React development project.
2. TypeScript's TSX files contain typed JSX.
3. Tailwind's Vite plugin must be registered.
4. Import Tailwind CSS from your global stylesheet.
5. main.tsx mounts React in the root HTML element.
6. App.tsx describes the initial visible interface.
7. Run npm run dev and open the displayed local URL.
8. Verify the first screen before adding more complexity.
