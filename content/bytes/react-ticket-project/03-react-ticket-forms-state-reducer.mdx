## Understand the concept first

Controlled form fields keep typed values in React state. useReducer can express create, status change and assignment as explicit actions. Reject empty subject values and preserve immutable updates.

In plain language, an interface should show useful information and respond predictably to users. We begin with one small technical change before introducing more features.

### Step 1 — Create a reducer for changes

**Edit or create the indicated file.**

```tsx
// src/ticketReducer.ts
import type {Ticket} from './data/tickets';
export type Action={type:'add';ticket:Ticket}|{type:'status';id:number;status:Ticket['status']};
export function ticketReducer(state:Ticket[],action:Action):Ticket[]{
 switch(action.type){
 case 'add':return [...state,action.ticket];
 case 'status':return state.map(t=>t.id===action.id?{...t,status:action.status}:t);
 }
}
```

## Key Takeaways

1. Controlled inputs keep form values in React state.
2. Validation rejects an empty issue title.
3. useReducer centralizes related ticket transitions.
4. Actions describe an add or resolve request.
5. Reducers must return new state rather than mutate old data.
6. A ticket id identifies the record to update.
7. Derived Open counts change when ticket status changes.
8. Errors must be readable and recoverable.
