## Karthik-oda WhatsApp bot: reply pannuma, work-ai mudikkuma?

**AI agent என்பது ஒரு goal-ஐ achieve செய்ய AI use செய்து, user சார்பாக bounded tasks complete செய்யும் software system.** அது next step choose பண்ணலாம், authorised tools use பண்ணலாம், result observe பண்ணலாம், goal complete ஆகும் வரை continue பண்ணலாம். Permission அல்லது information இல்லாத boundary வந்தால் மனிதரிடம் கேட்க வேண்டும்.

Chatbot பொதுவாக ஒரு message-க்கு answer கொடுக்கும். Copilot human work செய்யும்போது assist பண்ணும். Agent ஒரு bounded outcome-க்கு தேவையான steps-ஐ coordinate பண்ணும்—உதாரணமாக meeting time options கண்டுபிடித்து approval-க்கு தயார் செய்வது.

Agent என்றால் unlimited freedom இல்லை. Clear goal, limited permission, completion rule மற்றும் important actions-க்கு human approval தேவை.

## Simplest agent loop

<HandbookLearningVisual variant="agentFoundation" />

Request: **“Next week project review-க்கு suitable ஆன மூன்று நேரங்களை கண்டுபிடி.”**

1. **Goal:** Attendees மற்றும் time window-ஐ புரிந்துகொள்.
2. **Plan:** Calendars check செய்து common slots கண்டுபிடிக்க முடிவு செய்.
3. **Tool:** User authorise செய்த calendars மட்டும் read செய்.
4. **Action:** Time zone உடன் மூன்று options prepare செய்.
5. **Check:** எல்லா required attendees-மும் available-ஆ என்று confirm செய்.

Invitation send செய்வதற்கு explicit permission இல்லையென்றால் agent stop ஆக வேண்டும். Availability read பண்ணுவதும் event create பண்ணுவதும் different consequences.

## Chatbot, copilot மற்றும் agent வித்தியாசம்

| System | Neenga கேட்பது | அது பொதுவாக செய்வது | Next step யார் drive பண்ணுவது? |
|---|---|---|---|
| Chatbot | “Project review agenda-ல் என்ன இருக்க வேண்டும்?” | Answer generate செய்யும் | Person |
| Copilot | “இந்த agenda prepare செய்ய help பண்ணு” | Human-உடன் suggest மற்றும் edit செய்யும் | Person |
| AI agent | “Approved project data use செய்து review brief prepare பண்ணு” | Plan, source read, result prepare மற்றும் completeness check செய்யும் | Human limits-க்குள் agent |

Product பெயர் assistant, copilot அல்லது agent என்று இருந்தாலும் behaviour-ஐ பாருங்க: system action choose செய்து tools use செய்து goal நோக்கி continue செய்கிறதா?

## Real-time scenario: business trip planning

<Scenario title="Travel question-லிருந்து travel outcome வரை">

Chatbot Bengaluru-லிருந்து Chennai செல்ல options explain பண்ணும். Copilot நீங்க கொடுத்த trains மற்றும் flights-ஐ compare பண்ணும். Travel agent authorised services-ல் search செய்து time, budget அடிப்படையில் itinerary prepare பண்ணி booking அல்லது payment முன் approval கேட்கும்.

</Scenario>

## Agent எங்கே useful?

- Authorised project sources-லிருந்து weekly status report prepare பண்ண.
- Multiple calendars-ல் appointment options கண்டுபிடிக்க.
- Support requests review செய்து reply drafts prepare பண்ண.
- Approved suppliers-ஐ checklist அடிப்படையில் compare பண்ண.
- Application incident வந்தால் evidence collect செய்து summary prepare பண்ண.

Every step fixed என்றால் normal automation simpler. Explanation மட்டும் வேண்டுமென்றால் chatbot போதும்.

## Autonomy-க்கு boundaries தேவை

<AgentBoundaryVisual />

Search, read, organise மற்றும் draft போன்ற low-risk preparation-ஐ limited permission-ல் allow பண்ணலாம். Message send, money spend, data delete, access change அல்லது high-impact decision-க்கு stronger control மற்றும் human approval தேவை.

## No-code thinking exercise

I want an AI agent to help with this outcome:

Create a beginner-friendly agent brief with:

2. Information it may read

4. Automatic actions

6. Completion checks
7. Stop-and-ask situations

## Common mistakes

<Mistakes>

- Tool use அல்லது goal pursuit இல்லாத chatbot-ஐ agent என்று அழைப்பது.
- “Complete” என்றால் என்ன என்று define பண்ணாமல் broad goal கொடுப்பது.
- Send, purchase அல்லது delete actions-ஐ approval இல்லாமல் allow பண்ணுவது.
- Basic workflow useful-ஆ என்று prove செய்வதற்கு முன் நிறைய tools connect பண்ணுவது.
- Confident action correct என்று result check செய்யாமல் assume பண்ணுவது.

</Mistakes>

## நினைவில் வைக்க வேண்டிய key points

<Takeaways>

- Agent goal-oriented; conversational மட்டும் இல்லை.
- Tools மூலம் external information read அல்லது action perform செய்ய முடியும்.
- Basic loop: goal → plan → tool → action → check.
- அதிக autonomy-க்கு clearer permissions மற்றும் stop rules தேவை.
- Trend அடிப்படையில் அல்ல; work அடிப்படையில் chatbot, copilot, automation அல்லது agent choose பண்ணுங்க.

</Takeaways>
