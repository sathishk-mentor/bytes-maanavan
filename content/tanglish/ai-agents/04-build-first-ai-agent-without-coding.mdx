## Karthik-oda agent order place panna munnadi

Wrong reply draft inconvenient. Wrong paid order direct cost create pannum. Adhanala same workflow-oda ovvoru stage-kum different control venum.

## Check panna vendiya seven risks

1. **Context and hallucination:** wrong illa old information use pannuradhu.
2. **Action and orchestration:** wrong tool, target, sequence illa duplicate action.
3. **Security and access:** thevai-ku mela permission kudukkaradhu.
4. **Privacy and compliance:** personal data unnecessary-aa use illa retain pannuradhu.
5. **Operational and cost:** retry loop, duplicate transaction, uncontrolled usage.
6. **Fairness and harm:** high-impact decision-la unfair result.
7. **Reputation and accountability:** problem vandha owner yaaru-nu clear illama irukkaradhu.

## Human approval meaningful-aa irukkanum

Exact action, target, final content illa amount, evidence, uncertainty and impact-ai show pannunga. Generic “Continue?” button podhaadhu. Money, employment, health, legal rights and sensitive data related work-ku qualified human review thevai.

## Common mistakes

<Mistakes>

- Narrow task-ku broad permanent access kudukkaradhu.
- Agent “done” sonna action success-nu assume pannuradhu.
- Exact impact kaattama approval kekkaradhu.
- Failure-ai repeated-aa retry panni duplicate create pannuradhu.
- Sensitive data-ku retention rule illama save pannuradhu.
- Owner and recovery plan illama launch pannuradhu.

</Mistakes>

## Key takeaways

<Takeaways>

- Generated text external action aagumbodhu risk increase aagum.
- Data, permission, validation, approval, logs and stop rules together venum.
- Consequential action-ku fresh, informed approval thevai.
- Tool confirmation dhaan action success evidence.
- Evidence illa authority illa-na safe-aa stop pannuradhu correct result.

</Takeaways>
