## Start from Basics

- **Dockerfile:** Image எப்படி build ஆகணும் என்று சொல்லும் instruction file.
- **Image:** App மற்றும் அது start ஆக தேவையான files சேர்த்து prepare செய்த package. இது இன்னும் run ஆகவில்லை.
- **Container:** Image-லிருந்து start ஆன running app copy.
- **Registry:** Images store மற்றும் share செய்யும் place; Docker Hub ஒரு example.
- **Tag:** Image version identify செய்யும் label, example `1.0`.
- **Docker Engine:** Dockerfile instructions follow பண்ணி image build செய்து container start செய்யும் Docker software.

## Core Explanation

<DockerConceptLab concept="imageContainer" language="ta" />

Flow ரொம்ப simple. Dockerfile என்பது recipe. Docker அந்த recipe-ஐ follow பண்ணி image என்ற ready package-ஐ create பண்ணும். அந்த image-ஐ start பண்ணும்போது container என்ற running app கிடைக்கும்.

Team image-ஐ registry என்ற online store-ல் save பண்ணலாம். இன்னொரு developer அந்த exact image-ஐ download செய்து புதிய container start பண்ணலாம். அவரவர் laptop-ல் setup steps guess பண்ண வேண்டிய அவசியம் குறையும்.

### One app எப்படி container ஆகுது?

1. Karthik கிட்ட `app.py` மற்றும் required Python libraries list இருக்கு.
2. எந்த Python version use பண்ணணும், எந்த files copy பண்ணணும், app எப்படி start ஆகணும் என்று Dockerfile-ல் எழுதுகிறார்.
3. Docker அந்த instructions-ஐ read பண்ணி `order-app:1.0` என்ற image build பண்ணும்.
4. அந்த image-ஐ start செய்ததும் Docker ஒரு container create பண்ணும்; app run ஆக ஆரம்பிக்கும்.
5. QA அதே `order-app:1.0` image-லிருந்து இன்னொரு container start பண்ணலாம். இருவரும் same prepared setup use பண்ணுகிறார்கள்.

Image original ready package மாதிரி safe-ஆ இருக்கும். Container start பண்ணினால் image காலியாகாது அல்லது disappear ஆகாது. One container stop ஆனாலும் same image-லிருந்து another container start பண்ணலாம்.

Container என்பது இன்னொரு full computer இல்லை. அது host operating system-ன் ஒரு பகுதியை share செய்து separate process-ஆ run ஆகும். Virtual machine-ல் full guest operating system இருக்கும். Beginner level-ல் நினைவில் வைக்க வேண்டியது: container பொதுவாக quick-ஆ start ஆகும்; VM அதிகமான system files உடன் வரும்.

### App folder-ஐ ZIP செய்து send பண்ணினால் போதாதா?

ZIP file source code-ஐ மட்டும் கொண்டு போகலாம். Friend laptop-ல் correct Python version அல்லது required library இல்லையென்றால் app இன்னும் start ஆகாது. Docker image app-உடன் required setup-யும் prepared package-ஆ வைத்திருக்கும். Friend machine-ல் Docker இருக்கணும்; ஆனால் long manual setup steps குறையும்.

### Image vs container — easy check

| Question | Image | Container |
|---|---|---|
| App இப்போ run ஆகுதா? | இல்லை | ஆம் |
| Team save மற்றும் share செய்யுமா? | ஆம் | பொதுவாக image-ஐ தான் share செய்வார்கள் |
| Multiple running copies create செய்ய முடியுமா? | ஆம் | ஒவ்வொரு copy-யும் separate container |
| One container stop ஆனால்? | Image அப்படியே இருக்கும் | அந்த running copy மட்டும் stop ஆகும் |

## Docker Container vs Virtual Machine

| Question | Container | Virtual Machine |
|---|---|---|
| OS | Host kernel share பண்ணும் | Full guest OS run பண்ணும் |
| Startup | பொதுவாக seconds | பொதுவாக அதிக நேரம் |
| Package | App + dependencies | App + dependencies + full OS |
| Best fit | Portable app workloads | Strong isolation அல்லது different OS |

Container always better இல்லை. Requirement பார்த்து choose பண்ணணும்.

## FAQ + Knowledge Check

**Docker install செய்தால் app bugs fix ஆகுமா?** இல்லை. Environment mismatch reduce ஆகும்; application bugs தனியாக fix செய்யணும்.

**One image-லிருந்து multiple containers run பண்ணலாமா?** ஆம். ஒவ்வொரு container-மும் separate running copy.
