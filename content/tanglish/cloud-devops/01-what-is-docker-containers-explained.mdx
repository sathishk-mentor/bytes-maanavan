## Image vs Container
| Question | Image | Container |
|---|---|---|
| App run aagudha? | Illai | Aam |
| Share pannalama? | Aam | Usually image-ai share pannuvom |
| One package-la multiple copies? | Aam | Ovvoru copy-um separate container |
| Stop aana enna aagum? | Image safe-a irukkum | Andha running instance stop aagum |

## Container vs Virtual Machine
| Decision | Container | Virtual machine |
|---|---|---|
| Operating system | Host kernel share pannum | Full guest OS run pannum |
| Startup | Usually fast | Usually slow |
| Package size | App + dependencies | App + dependencies + guest OS |
