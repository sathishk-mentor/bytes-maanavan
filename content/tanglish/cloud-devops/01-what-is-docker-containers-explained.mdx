## S1 🚀 Quick Start

Karthik build பண்ணிய Python app அவருடைய laptop-ல் work ஆகுது. Team member run பண்ணும்போது `package not found`; server-ல் Python version mismatch. Code same—but setup different.

Docker use பண்ணினால் app code, runtime மற்றும் dependencies எல்லாத்தையும் ஒரே package-ஆக எடுத்துச் செல்லலாம். இதுதான் “works on my machine” problem-க்கு practical answer. Docker எல்லா bugs-ஐயும் solve பண்ணாது; environment difference-ஐ control பண்ணும்.

## S2 📖 Start from Basics

- **Dockerfile:** Image எப்படி build ஆகணும் என்று சொல்லும் instruction file.
- **Image:** App run ஆக required files கொண்ட read-only package.
- **Container:** Image-லிருந்து start ஆன running instance.
- **Registry:** Images store மற்றும் share செய்யும் place; Docker Hub ஒரு example.
- **Tag:** Image version identify செய்யும் label, example `1.0`.
- **Docker Engine:** Image build மற்றும் container run செய்யும் runtime.

## S3 🧠 Core Explanation

Flow simple: developer Dockerfile எழுதுகிறார் → Docker image build பண்ணுது → team அந்த image-ஐ registry-லிருந்து pull பண்ணுது → container start பண்ணுது. Running container-க்குள் manual fix பண்ணக்கூடாது. Source அல்லது Dockerfile change செய்து new image build பண்ணணும்; அப்போதுதான் result repeatable.

Container VM கிடையாது. அது host OS kernel-ஐ share செய்து isolated process-ஆக run ஆகும். அதனால் startup fast; resource usage பொதுவாக குறைவு. But permissions, resource limits மற்றும் security checks இன்னும் தேவை.

## S5 🧩 Types / Components

Image layers build cache-க்கு help பண்ணும். Container-க்கு writable runtime layer கிடைக்கும்; container delete ஆனால் அந்த layer data போகலாம். Registry team distribution-க்கு useful. Volume persistent data-க்கு; network containers communicate செய்ய; environment variables runtime settings கொடுக்க use ஆகும்—இவற்றை next Bytes-ல் பார்க்கலாம்.

## S6 ⚖️ Docker Container vs Virtual Machine

| Question | Container | Virtual Machine |
|---|---|---|
| OS | Host kernel share பண்ணும் | Full guest OS run பண்ணும் |
| Startup | பொதுவாக seconds | பொதுவாக அதிக நேரம் |
| Package | App + dependencies | App + dependencies + full OS |
| Best fit | Portable app workloads | Strong isolation அல்லது different OS |

Container always better இல்லை. Requirement பார்த்து choose பண்ணணும்.
