## Quick Start
Docker commands copy panna munnadi app enna seyyudhu-nu purinjukkanum. Namma sample Flask app `/health` endpoint-la service healthy-nu JSON return pannum.

## Start from Basics
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.get("/health")
def health():
    return jsonify(status="healthy", service="maanavan-demo")

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8000)
```

`requirements.txt`:
```text
Flask==3.1.2
```

## Dockerfile-ai Decision-by-Decision Read Pannunga
```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY app.py .
EXPOSE 8000
CMD ["python", "app.py"]
```

| Instruction | Meaning |
|---|---|
| `FROM` | Base runtime choose pannum |
| `WORKDIR` | App working folder set pannum |
| `COPY` | Required files image-kulla copy pannum |
| `RUN` | Build time command execute pannum |
| `EXPOSE` | App expected port-ai document pannum |
| `CMD` | Container start aagumbodhu run aagura process |

## Build Context-ai Clean-a Vaikkalam
`.dockerignore` file-la `.git`, `.venv`, `.env`, `__pycache__` madhiri local or sensitive files-ai exclude pannunga. Idhu build context-ai small-a maintain pannum.

## Build, Run, Verify
```bash
docker build -t python-health:1.0 .
docker run --rm --name python-health -p 8000:8000 python-health:1.0
curl http://localhost:8000/health
```

Expected result:
```json
{"service":"maanavan-demo","status":"healthy"}
```

`docker build` image create pannum. `docker run` andha image-la irundhu container start pannum. Code change pannina image-ai rebuild pannanum.
