## Ports: App Door-ai Connect Pannuvom
```bash
docker run --name api -p 8080:8000 python-health:1.0
```
Format `HOST_PORT:CONTAINER_PORT`. Browser `localhost:8080` request, container-oda port `8000`-ku forward aagum. App `0.0.0.0:8000`-la listen pannanum.

## Volumes: Important Data-ai Preserve Pannuvom
```bash
docker volume create app-data
docker run --name api -v app-data:/app/uploads python-health:1.0
```
Container delete/recreate aanaalum named volume-la selected files remain aagum. Aana volume backup automatic illa.

## Environment Variables: Same Image, Different Settings
```bash
docker run --name api \
  -e APP_ENV=staging \
  -e MODEL_NAME=approved-model \
  python-health:1.0
```
Same image-ai development, staging, production-la different runtime configuration-oda use pannalaam. API keys-ai Dockerfile-la bake panna koodadhu.

## Correct Tool-ai Choose Pannunga
| Need | Correct choice | Wrong assumption |
|---|---|---|
| Browser access | Port mapping | `EXPOSE` mattum podhum |
| Persistent uploads | Volume/external storage | Container writable layer podhum |
| Environment setting | Runtime configuration | New image for every value |
| Sensitive key | Platform secret manager | Plain `.env` commit pannalaam |
