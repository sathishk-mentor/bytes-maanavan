## Practical Compose Definition
```yaml
services:
  backend:
    build: ./backend
    environment:
      DATABASE_URL: postgresql://app:app@postgres:5432/app
    depends_on:
      postgres:
        condition: service_healthy

  postgres:
    image: postgres:17
    volumes:
      - postgres-data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U app"]
      interval: 10s
      retries: 5

volumes:
  postgres-data:
```
Example password learning purpose mattum; production-la secret manager use pannanum.

## Startup vs Readiness

## Operate the Stack
```bash
docker compose up --build
docker compose ps
docker compose logs -f backend
docker compose exec backend sh
docker compose down
```
`docker compose down -v` volumes-ai delete panna mudiyum; data remove panna intention irundha mattum use pannunga.

## Run Commands vs Compose
| Decision | Separate commands | Compose |
|---|---|---|
| Definition | Multiple terminal commands | One reviewed YAML file |
| Networking | Manual setup | Service names available |
| Repeatability | Options miss aagalaam | Shared definition |
| Best fit | Quick single container | Connected local stack |
