## Production-Minded Image
```dockerfile
FROM python:3.12-slim
ENV PYTHONDONTWRITEBYTECODE=1 PYTHONUNBUFFERED=1
WORKDIR /app
RUN addgroup --system app && adduser --system --ingroup app app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY --chown=app:app app.py .
USER app
EXPOSE 8000
CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]
```
Image non-root user-la run aagudhu. Dependencies source-kku munnadi install aaguradhu build cache-ku help pannum.

## Local vs Production
| Question | Local container | Production service |
|---|---|---|
| Access | Developer localhost | Authenticated ingress |
| Key | Local runtime variable | Platform secret manager |
| Success evidence | One request works | Health + quality + latency + safety + cost |
| Failure handling | Manual restart | Alert, controlled rollout, rollback |
