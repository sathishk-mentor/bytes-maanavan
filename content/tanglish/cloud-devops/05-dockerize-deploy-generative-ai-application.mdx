## Application boundary என்ன?

Food-delivery support API user question-ஐ validate செய்து, approved order context-ஐ retrieve செய்து, LLM provider-ஐ call செய்து bounded answer return செய்யும். Image-ல் code மற்றும் dependencies இருக்க வேண்டும்; API key deployment environment-லிருந்து runtime-ல் வர வேண்டும்.

```python
import os
from fastapi import FastAPI, HTTPException

app = FastAPI()

@app.get("/health")
def health():
    return {"status": "healthy"}

@app.post("/support")
def support(question: str):
    if not os.getenv("LLM_API_KEY"):
        raise HTTPException(500, "LLM provider is not configured")
    return {"answer": f"Demo response for: {question}"}
```

## Production-minded image

```dockerfile
FROM python:3.12-slim
WORKDIR /app
RUN addgroup --system app && adduser --system --ingroup app app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY --chown=app:app app.py .
USER app
EXPOSE 8000
CMD ["uvicorn", "app:app", "--host", "0.0.0.0", "--port", "8000"]
```

Small trusted base image, dependency layer caching மற்றும் non-root user நல்ல defaults. Tested versions-ஐ pin செய்து final image-ஐ scan பண்ண வேண்டும்.

## Secret-ஐ image-ல் bake பண்ணாதீங்க

`ENV LLM_API_KEY=...` அல்லது `COPY .env .` image history-ல் secret leak செய்யலாம். Local-ல் runtime environment variable; production-ல் platform secret manager மற்றும் least-privilege access use செய்யுங்கள்.

User request HTTPS ingress வழியாக API container-க்கு வரும். Container secret manager, order database மற்றும் LLM provider-ஐ controlled access மூலம் use செய்யும். Logs, metrics மற்றும் traces request outcome-ஐ record செய்யும்.

## Real-time scenario: delayed order assistant

<Scenario title="Demo start ஆகுவது மட்டும் success இல்லை">

நூற்றுக்கணக்கான customers “என் order எங்கே?” என்று ஒரே நேரத்தில் கேட்கலாம். Provider மெதுவாகலாம்; user மிக நீளமான input அனுப்பலாம்; கட்டுப்பாடற்ற retry loop cost-ஐ அதிகரிக்கலாம். Team input limit, timeout, concurrency limit, token budget மற்றும் rollback policy அமைக்கிறது. Container running நிலையில் இருப்பதை மட்டும் பார்க்காமல் answer பாதுகாப்பாகவும், சரியான நேரத்திலும், கட்டுப்படுத்தப்பட்ட செலவிலும் கிடைக்கிறதா என்று அளவிடுகிறது.

## Health checks வேறுபாடு

| Check | அது சொல்லும் விஷயம் |
|---|---|
| Liveness | Process உயிருடன் இருக்கிறதா? |
| Readiness | New traffic receive செய்யலாமா? |
| Evaluation | Answer expected quality meet ஆகிறதா? |
| Cost metric | Request ஒன்றுக்கு tokens/cost எவ்வளவு? |

Paid LLM call-ஐ frequent liveness probe-ஆக use பண்ணாதீங்க.

## Deployment checklist

1. Image-க்கு immutable version tag கொடுங்கள்.
2. Dependencies மற்றும் image vulnerabilities scan செய்யுங்கள்.
3. Non-root process confirm செய்யுங்கள்.
4. Secrets runtime-ல் inject செய்யுங்கள்.
5. CPU, memory, concurrency, timeout limits set செய்யுங்கள்.
6. Quality, latency, errors மற்றும் cost observe செய்யுங்கள்.
7. Limited traffic-க்கு release செய்து rollback path-ஐ ready-ஆக வைத்திருங்கள்.

## Troubleshooting map

| Symptom | முதலில் பார்க்க வேண்டிய evidence | சாத்தியமான காரணம் |
|---|---|---|
| Container மீண்டும் மீண்டும் restart ஆகிறது | Platform events மற்றும் startup logs | Missing variable, wrong command அல்லது memory limit |
| Request timeout ஆகிறது | Dependency latency trace | Provider delay, network அல்லது timeout mismatch |
| Provider `401` return செய்கிறது | Safe error category மற்றும் secret version | Invalid, expired அல்லது unauthorized key |
| Local-ல் works; cloud-ல் fail | Bind address, port மற்றும் platform contract | Wrong port அல்லது `localhost` binding |
| Cost திடீரென உயர்கிறது | Request count, tokens மற்றும் retry metrics | Unbounded input, retry storm அல்லது abuse |
| Release-க்குப் பிறகு answer quality குறைகிறது | Evaluation results by version | Prompt, model, retrieval அல்லது data change |

## Common mistakes

<Mistakes>

- Provider key-ஐ Dockerfile அல்லது image context-ல் copy செய்வது.
- Every provider error-ஐ retry செய்து cost storm உருவாக்குவது.
- `latest` tag மட்டும் deploy செய்து rollback version தெரியாமல் போவது.
- Full private prompts-ஐ logs-ல் store செய்வது.
- Infrastructure uptime மட்டும் பார்த்து answer quality ignore செய்வது.

</Mistakes>

## Interview-ல் எப்படி விளக்குவது?

Secrets இல்லாத minimal, versioned image உருவாக்கி non-root user-ஆக run செய்வேன். Deployment platform secret manager மூலம் provider key inject செய்யும். Limited traffic release மற்றும் tested rollback path வைத்திருப்பேன்.
