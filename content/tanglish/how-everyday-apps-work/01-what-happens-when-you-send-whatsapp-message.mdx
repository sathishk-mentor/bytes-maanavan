## Oru tap-ku appuram enna nadakkum?

Meena, Karthik-ku WhatsApp-la “Meeting 5 mani-ku” nu message anuppuraanga. Udane oru grey tick varudhu. Karthik-oda phone switch off. Appo message enga irukku? Rendu ticks eppo varum?

**Simple answer:** Meena-oda phone message-ai anuppum. Messaging service adhai receive panni, recipient available-a irundha deliver pannum. Illaina, later deliver panna hold pannum. Recipient device receive pannina appuram delivery status update aagum.

## Tick-ku oru precise meaning irukku

| Meena paakradhu | Adhu sollum event |
|---|---|
| Oru grey tick | Message service-ku send aayiduchu; recipient device-ku delivery confirm aagala |
| Rendu grey ticks | Recipient device-ku deliver aayiduchu |
| Rendu blue ticks | Read receipt available-a irundha, message viewed-nu kaattum |

**“Delivered” na “padichuttaanga” nu artham illa.** Read receipts settings, group chats, connection state madhiri details visible ticks-ai affect pannalam. Ticks-ai use panni oruthar enna ninaikkiraanga-nu guess panna koodadhu.

## Phone offline aana?

1. Meena Send tap pannuraanga; app message-ai service-ku anuppudhu.
2. Service recipient-ku delivery try pannudhu.
3. Karthik phone offline-na, pending delivery state-la message wait pannudhu.
4. Phone reconnect aanadhum delivery try aagudhu.
5. Device acknowledgement vandha dhaan delivered status theriyum.

Idhai **queue** nu nenachukkonga: parcel courier office-la wait pannum; veetla yaaravadhu irukkumbodhu deliver pannuvaanga. Indha analogy delivery timing-ku mattum. WhatsApp-oda exact private infrastructure inga claim pannala.

## Group message-la enna maarum?

One-to-one-la oru recipient. Group-la many recipients. 50-member group-la 10 per offline-na, online irukkura 40 devices-ku delivery nadakkalam; offline 10-ku later try panna vendum. Oru member offline irukkaradhu naala ellaroda message-um block aaga koodadhu. Each recipient-oda delivery state-ai separately think pannunga.

## Try pannunga

Unga friend train-la network illama travel panraanga. Message-ku oru tick mattum irukku. Avanga network-ku thirumbi vandha appuram enna three events nadakkanum? **Hint:** reconnect → pending delivery → acknowledgement.

## Ninaivil vechukka

- Send, deliver, view — moonum ore action illa.
- Recipient offline iruppadhu normal condition; pending delivery handle pannanum.
- Status indicator oru real event-ai represent pannanum.
- Exact WhatsApp internals full-a public illa; indha flow beginner mental model.

## Common questions

**Oru tick-na block pannitaangala?** Adha ticks mattum vechu decide panna mudiyaadhu. Delivery confirmation innum varala-nu mattum sollalam.

**End-to-end encryption irundha service epdi route pannum?** Service delivery-ku thevaiyaana routing information-ai handle pannalam; message content-ai padikka thevai illa.
