## Concept-ai Simple-a Purinjukonga

Simple-a solna: LangChain-la **model** nu solradhu, oru "universal remote" madhiri nenachukonga. Neenga TV company edhuvaa irundhalum, andha remote-oda basic buttons — power, volume, channel — ellam same feel pannum. Adhu madhiri, LangChain-oda model interface, provider edhuvaa irundhalum (OpenAI, Anthropic Claude, Google Gemini, illa nee local-a Ollama run pannalam), ஒரே மாதிரி code pattern-la call panna mudiyum.

Rendu main types iruku:

1. **LLM (text completion)** — pழைய style, plain text-ah input-ah kudutha, plain text output tharum.
2. **ChatModel (conversation-aware)** — indha kaalathula ithu dhaan common. System message, human message, AI message-nu structure-a pesuvom. Ithu dhaan ChatGPT madhiri conversational feel kudukudhu.

Rahul kekkuraan: "Divya akka, chat model-nu use pannaama LLM use pannalamla?" Divya: "Pannalam Rahul, aana chat-based apps-ku — memory, roles ellam handle panna — ChatModel dhaan best fit. 2024-kku apram almost ella major providers-um chat-first-a dhan design pannranga."

## Inside Workflow

Technical-a paakalam. Chat model call panna, moonu roles use pannuvom:

- **System** — model-oda behavior set pandradhu ("Neenga oru helpful finance assistant"-nu).
- **Human** — user-oda question.
- **AI** — model-oda previous response (conversation history maintain panna).

LangChain indha moonu-ah `SystemMessage`, `HumanMessage`, `AIMessage` classes-a wrap pannudhu, so ethana provider vandhalum format automatic-a handle aagum.

**Support panra key features** (chapter-la solradha madhiri):
- **Async calls** — `ainvoke()` use panni, ஒரே நேரத்தில் multiple requests handle panna mudiyum, app block aagadhu.
- **Streaming** — response full-a varaikkum wait pannama, token-token-a UI-la kaamikanum na `stream()` use pannuvom — ChatGPT-la typing effect paakuromla, adhu than.
- **Batch** — 100 customer questions-ah ஒரே நேரத்தில் process pannanumna `batch()`.

## Code Panni Paapom

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import SystemMessage, HumanMessage

# Model initialize pannurom - temperature low na consistent answers varum
model = ChatOpenAI(model="gpt-4o-mini", temperature=0.2)

messages = [
    SystemMessage(content="Neenga oru friendly personal finance assistant. Tanglish-la simple-a explain pannunga."),
    HumanMessage(content="Indha maasam en food expense evlo?")
]

response = model.invoke(messages)
print(response.content)

# Streaming example - real-time-a token vara vara print aagum
for chunk in model.stream(messages):
    print(chunk.content, end="", flush=True)
```

## Practical Cost Scenario

**Important:** Keela irukkura PaisaWise numbers concept explain panna use panra sample calculation. Idhu real company internal cost claim illa. Actual cost model, token usage, traffic and provider pricing-la depend aagum.

## Common Mistakes

1. **API key hardcode pannuradhu** — code-la direct-a key podadhinga, `.env` file use pannunga.
2. **Temperature wrong-a set pannuradhu** — factual answers-ku (balance check) temperature=0 use pannunga, creative content-ku (marketing copy) temperature=0.7+ use pannunga.
3. **Sync calls mattum use panni app slow aaguradhu** — production-la async/streaming consider pannama poi user-ah wait vaikuranga.
4. **Provider lock-in nenachu design pannuradhu** — LangChain-oda whole point dhaan provider swap panna easy-a irukanum-nu, aana konjam people provider-specific features (function calling format) heavy-a use panni, andha flexibility lose pannuranga.

## FAQ + Knowledge Check

**Q1: LangChain nu solna oru puthu LLM aa?**
Illa. LangChain oru framework/orchestration layer — existing LLMs (OpenAI, Anthropic, Gemini, etc.) ah connect panni, apps build panna help pannudhu.

**Q2: Streaming yaen important?**
User-ku "waiting" feel varama, response generate aaguravaraikkum real-time-a text kaamikardhukku. UX-ku romba முக்கியம்.

**Q3: Temperature parameter enna pannum?**
Model-oda "randomness" control pannum. Low (0-0.3) = consistent/factual, High (0.7-1) = creative/varied.

**Knowledge Check:**
1. Customer balance check bot-ku, temperature evlo set pannanum — 0.1 illa 0.9?
2. `ChatOpenAI`-ah `ChatAnthropic`-ku maathanum na, evlo code maatha vendiyirukum — approximately?
3. True/False: Async calls, app-ah multiple requests ஒரே நேரத்தில் handle panna help pannum.

*(Answers: 1. 0.1 — factual/consistent venum; 2. Minimal — mostly one line, class name mattum; 3. True)*
