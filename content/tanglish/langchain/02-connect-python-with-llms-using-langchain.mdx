## Concept-ai Simple-a Purinjukonga

**PromptTemplate**-ah oru "fill-in-the-blanks" letter madhiri nenachukonga — wedding invitation print pandringalla, "Dear {name}, please join us on {date}"-nu template vachu, ovvoru guest-kum name/date mattum maathringa. Adhu madhiri than, PromptTemplate-la fixed structure irukum, variables mattum maarum.

**Chains** — idhu "assembly line" madhiri. Factory-la, raw material ஒரு station-ல் இருந்து அடுத்த station-ku pogum — cutting → stitching → packing. Adhu madhiri, LangChain chain-la: **Prompt → Model → Output Parser** — ஒரு step-oda output, அடுத்த step-oda input-a become aagum. Idha **LCEL pipe operator** (`|`) use panni beautiful-a express pannalam.

Meena kekkuraanga: "Chain-nu solna, evlo steps podalam?" Divya: "Evlo venumaa — 2 steps, 10 steps, even chain-ku-ulla chain-um podalam (sequential chains)."

---

## Inside Workflow

LCEL-la ovvoru component-um oru "Runnable" — adhukku `.invoke()`, `.stream()`, `.batch()` methods common-a irukum. `|` operator use panna, output-oda type, next component-oda expected input-type-oda match aaganum — adhu dhaan chain "work aaguradhu" nu solradhu.

**Sequential chains** — step 1-oda output, step 2-ku input-a pogudhu. Example: raw text → summarize pannu → adha translate pannu → adha categorize pannu.

**Output Parsers** — model-oda raw text response-ah, structured data-a (JSON, list, specific format) convert pannuradhu. Idhu romba important — because downstream code-ku (database save panna, UI-la kaamikka) structured data than venum, free-text illa.

## Code Panni Paapom

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser

# Reusable template - variables curly braces-la
prompt = ChatPromptTemplate.from_template(
    "Categorize this expense into ONE word (Food, Travel, Shopping, Bills, Other): {expense_text}"
)

model = ChatOpenAI(model="gpt-4o-mini", temperature=0)
parser = StrOutputParser()

# LCEL - pipe operator use panni chain build pannuradhu
chain = prompt | model | parser

result = chain.invoke({"expense_text": "Swiggy-la 450 rupees செலவு"})
print(result)  # Output: Food

# Batch - multiple expenses ஒரே நேரத்தில்
expenses = [
    {"expense_text": "Uber ride to airport, 800 rs"},
    {"expense_text": "Electricity bill 1200 rs"},
]
results = chain.batch(expenses)
print(results)  # ['Travel', 'Bills']
```

## Common Mistakes

1. **Prompt-la clear instructions illama iruradhu** — "categorize this" nu mattum solna, model free-text paragraph return pannalam. "Reply with ONE word only" madhiri explicit-a solanum.
2. **Output parser skip pannuradhu** — raw string-ah nேரடி-a use panna try pannuranga, apram downstream code-la parsing errors varum.
3. **Chain-ah over-engineer pannuradhu** — 2 steps podhum-nu irukku na, 5 steps venaam. Simple-a irunga first, complexity venumna mattum add pannunga.
4. **Type mismatch** — ஒரு component output (dict) அடுத்த component expect panra input (string) match aagalana, chain fail aagum.

## Compare Panni Decide Pannunga

| Approach | When to Use |
|---|---|
| Single prompt + model call | Simple one-shot tasks, prototyping |
| Chain (prompt \| model \| parser) | Multi-step processing, structured output needed |
| Sequential chain (chain of chains) | Complex workflows — summarize → translate → categorize |

## Key Takeaways

- **PromptTemplate** — reusable, variable-based prompts, hardcoded strings-ah replace pannudhu.
- **LCEL pipe operator (`|`)** — components-ah readable, composable pipelines-a join pannudhu.
- **Chains** — multi-step workflows enable pannudhu: prompt → model → parser, and beyond.
- **Output parsers** — free-text-ah structured data-a convert panni, downstream systems-ku usable-a maathudhu.
- Simple-a start pannunga, complexity venumna mattum add pannunga.

## FAQ + Knowledge Check

**Q1: PromptTemplate and f-string-ku enna difference?**
PromptTemplate reusable, validatable, and LangChain-oda other components-oda seamless-a integrate aagum. f-string manual, error-prone at scale.

**Q2: Chain-la ஒரு step fail aana enna aagum?**
Default-a, exception raise aagi chain stop aagum. Error handling venumna, `.with_retry()` illa try/except wrap pannalam.

**Q3: LCEL mandatory-aa?**
Illa, aana recommended — readable-a, streaming/async/batch automatic-a support pannum.
