## Concept-ai Simple-a Purinjukonga

Agent-ah oru "smart PA (personal assistant)" madhiri nenachukonga. Neenga PA-kitta "en flight book pannunga, Chennai to Bengaluru"-nu solna, PA ready-made script follow pannuradhu illa — PA **reason** pannுவாங்க: "Idhukku flight search tool venum, apram calendar check pannanum, apram book pannanum." Ovvoru step-um, next step decide panradhukku munnadi previous result paapaanga.

**Agent** = LLM + Tools + Reasoning Loop. Model-kitta oru "toolbox" kudukurom (example: `check_balance()`, `send_notification()`, `search_transactions()`). User question vandha, agent:

1. **Think** — "Idha answer panna, edhu tool venum?"
2. **Act** — andha tool-ah correct parameters-oda call pannுradhu.
3. **Observe** — tool-oda result paakuradhu.
4. **Repeat illa Final Answer** — innum info venumna, next tool call pannுradhu, illana final answer kudukuradhu.

Idha **ReAct pattern** (Reason + Act) nu solluvom. Rahul kekkuraan: "Model wrong tool choose panna maatengala?" Divya: "Panna mudியும், adhுku dhaan tool descriptions clear-a, well-documented-a irukanum."

## Inside Workflow

**Tools** — Python functions dhaan, aana LangChain-ku "idhu oru tool"-nu kaamikardhukku, name, description, and expected parameters define pannanum. Model, indha description paathu dhaan "idha eppo use pannanum"-nu decide pannும் — so description clear-a, specific-a irukanum.

**Function/Tool Calling** — modern LLMs (GPT-4, Claude) natively support pannுthu "structured tool calls" — model, plain text-ku pathila, "call `check_balance` with `user_id=12345`" madhiri structured output generate pannும். LangChain idha parse panni, actual function-ah call pannும்.

**Agent Executor** — indha whole loop (think → act → observe → repeat) manage panra component. Max iterations set panna mudியும் (infinite loop avoid panna), intermediate steps log panna mudியும் (debugging-ku).

## Code Panni Paapom

```python
from langchain.tools import tool
from langchain.agents import create_agent

# Tools define pannuradhu - clear description romba important
@tool
def check_balance(user_id: str) -> str:
    """Given a user_id, returns their current account balance in INR."""
    # Real app-la, idhu database query pannும்
    return f"Balance for {user_id}: Rs 24,500"

@tool
def get_recent_transactions(user_id: str, count: int = 5) -> str:
    """Returns the user's most recent N transactions."""
    return f"Last {count} transactions for {user_id}: Swiggy Rs450, Uber Rs800..."

agent = create_agent(
    model="provider:model-name",
    tools=[check_balance, get_recent_transactions],
    system_prompt=(
        "Neenga PaisaWise finance assistant. Read-only tools mattum use pannunga. "
        "Money transfer, refund or account change execute panna koodadhu."
    ),
)

result = agent.invoke({
    "messages": [{
        "role": "user",
        "content": "PW12345 account-oda balance evlo?"
    }]
})

print(result["messages"][-1].content)
# Agent: tool select pannum -> Python execute pannum -> observation return aagum -> answer varum
```

## Common Mistakes

1. **Tool description vague-a iruradhu** — "get data"-nu mattum sonna, model confuse aagும். "Given a user_id, returns current account balance in INR"-nu specific-a irukanum.
2. **Too many tools kudுthu confuse pannுradhu** — 20+ tools kudுthaal, model correct tool choose panna struggle pannும். Related tools-ah group pannunga, illa hierarchical agents consider pannunga.
3. **Max iterations set pannaama poradhu** — agent infinite loop-la sikki, cost and latency uncontrolled-a increase aagும்.
4. **Sensitive actions-ku confirmation illama iruradhu** — money transfer, data deletion madhiri irreversible actions-ku, agent-ah direct-a execute panna vidama, human-in-the-loop confirmation add pannunga.
5. **Tool errors handle pannaama poradhu** — API call fail aana, agent-ku graceful-a handle panna theriyanum, illana whole conversation crash aagும்.

## FAQ + Knowledge Check

**Q1: Agent and Chain-ku enna basic difference?**
Chain-la steps fixed-a, predetermined-a irukும் (A then B then C). Agent-la, model dynamically decide pannும் edhu step next-nu — flexible, aana less predictable.

**Q2: Agent-ah production-la deploy panna safe-aa?**
Safe-a panna mudியும், aana guardrails venும் — max iterations, tool access restrictions, sensitive actions-ku human confirmation, and proper error handling.

**Q3: Function calling and Agent, same-aa?**
Illa. Function calling, oru single model call-la "idha call pannunga"-nu structured output kudுkkும் feature. Agent, indha function calling-ah use panni, multi-step reasoning loop run pannும் higher-level system.

**Knowledge Check:**
1. ReAct pattern-la, ethana main steps iruku?
2. Agent-ku tool description yaen romba important?
3. True/False: Agents ku max_iterations set pannுradhu optional, skip pannalam.

*(Answers: 1. Naalu — Think, Act, Observe, Repeat/Final Answer; 2. Model, description paathu dhaan correct tool-ah choose pannும்; 3. False — infinite loop avoid panna essential)*
