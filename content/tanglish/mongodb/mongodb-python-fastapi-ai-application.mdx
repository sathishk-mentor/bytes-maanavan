## Quick Start
Aggregation pipeline-ல் ஒவ்வொரு stage-மும் ஒரு clear transformation செய்கிறது: filter, group, reshape, sort.

## Core Explanation
```javascript
db.events.aggregate([
  { $match: { event: "lesson_completed" } },
  { $group: { _id: "$learner_id", completed: { $sum: 1 } } },
  { $project: { _id: 0, learner_id: "$_id", completed: 1 } }
])
```
`$match` early-ஆ இருந்தால் later stages குறைந்த documents மட்டும் process செய்யும்.

## Common Mistakes
<Mistakes>

- Filter செய்யும் முன் group செய்வது.
- Consumer-க்கு தேவையில்லாத fields return செய்வது.
- ML feature-ல் future information leak செய்வது.

</Mistakes>

## Key Takeaways
<Takeaways>

- Pipeline stage-by-stage transform செய்கிறது.
- Stage order முக்கியம்.
- Early filter efficient.
- Correct business grain-ல் group செய்யுங்கள்.
- Stable output project செய்யுங்கள்.
- Intermediate results inspect செய்யுங்கள்.
- Time cut-off protect செய்யுங்கள்.
- Realistic volume-ல் test செய்யுங்கள்.

</Takeaways>
