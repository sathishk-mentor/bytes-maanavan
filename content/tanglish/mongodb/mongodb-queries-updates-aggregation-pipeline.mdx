## History vs Memory
| History | Memory |
|---|---|
| Recorded events | Selected future context |
| On-demand load | Relevant ஆனபோது மட்டும் |
| Retention policy | Purpose + user control |

## Common Mistakes
<Mistakes>

- Full history-ஐ ஒவ்வொரு prompt-லும் load செய்வது.
- User ownership filter மறப்பது.
- Sensitive detail-க்கு expiry இல்லாமல் வைத்திருப்பது.

</Mistakes>

## Key Takeaways
<Takeaways>

- History மற்றும் memory வேறு.
- User மற்றும் session scope அவசியம்.
- Current task-க்கு தேவையான context மட்டும் load செய்யுங்கள்.
- Preferences-ஐ messages-இலிருந்து separate செய்யுங்கள்.
- User correct/delete செய்ய முடியும்.
- Retention deliberate-ஆ இருக்க வேண்டும்.
- Sensitive records protect செய்ய வேண்டும்.
- Summary-க்கு source link வைத்திருங்கள்.

</Takeaways>
