## Common Mistakes
<Mistakes>

- Outage பிறகு மட்டும் index add செய்வது.
- Unused indexes அதிகமாக உருவாக்குவது.
- Authenticated owner filter மறப்பது.
- Restore test இல்லாமல் backup-ஐ நம்புவது.

</Mistakes>

## Key Takeaways
<Takeaways>

- Real query shape-ல் இருந்து index design செய்யுங்கள்.
- Execution stats மூலம் verify செய்யுங்கள்.
- Field மற்றும் vector indexes வேறு.
- Ownership scope enforce செய்யுங்கள்.
- Least-privilege role பயன்படுத்துங்கள்.
- Retention/archive rules define செய்யுங்கள்.
- Latency, errors, capacity monitor செய்யுங்கள்.
- Recovery procedure test செய்யுங்கள்.

</Takeaways>
