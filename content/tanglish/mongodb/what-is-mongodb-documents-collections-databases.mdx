## Quick Start
MongoDB, JSON மாதிரியான **documents**-ஐ **collections**-ல் store செய்கிறது. Simple reply, tool call, retrieved evidence—ஒவ்வொரு interaction-க்கும் தேவையான fields மட்டும் இருக்கலாம்.

## Start from Basics
`database → collection → document → field` என்பது core hierarchy. Flexible shape இருந்தாலும் `session_id`, timestamps, field names போன்ற core contract consistent-ஆ இருக்க வேண்டும்.

## Core Explanation
```javascript
{ session_id: "sess_2291", user_message: "Balance check pannunga",
  tool_calls: [{ tool: "getBalance", result: 45230.50 }] }
```
Nested objects மற்றும் arrays ஒரே business record-க்குள் related data-ஐ வைத்திருக்க உதவும்.

## Common Mistakes
<Mistakes>

- Flexible schema என்ற பெயரில் inconsistent field names பயன்படுத்துவது.
- Independently change ஆகும் data-ஐ பல documents-ல் duplicate செய்வது.
- Dates-ஐ plain display string-ஆக store செய்வது.

</Mistakes>

## Key Takeaways
<Takeaways>

- MongoDB BSON documents பயன்படுத்துகிறது.
- Documents nested objects மற்றும் arrays support செய்கின்றன.
- Optional fields real variation-க்கு உதவும்.
- Core structure intentional-ஆ இருக்க வேண்டும்.
- Together read செய்யும் small data-ஐ embed செய்யலாம்.
- Separate lifecycle உள்ள data-ஐ reference செய்யலாம்.
- Critical fields validate செய்ய வேண்டும்.
- Access pattern பார்த்து model செய்ய வேண்டும்.

</Takeaways>
