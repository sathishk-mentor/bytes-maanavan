## Chatbot, copilot மற்றும் agent வித்தியாசம்

| Pattern | எப்படி behave செய்யும் | Example |
|---|---|---|
| Chatbot | Response generate செய்யும் | Python error explain பண்ணும் |
| Copilot | Human செய்யும் work-க்கு assist பண்ணும் | Review-க்கு study plan draft பண்ணும் |
| Agent | Tool steps choose செய்து perform செய்யும் | Goal read செய்து courses check பண்ணி path calculate செய்யும் |

Agent loop: goal-ஐ understand பண்ணும், next useful step choose பண்ணும், tool call பண்ணும், actual result observe பண்ணும், பிறகு continue செய்யலாமா stop செய்யலாமா decide பண்ணும்.

## Bounded Python tools create பண்ணுவது

```python
def calculate_weeks(total_hours: int, weekly_hours: int) -> int:
    if weekly_hours <= 0:
        raise ValueError("weekly_hours must be positive")
    return (total_hours + weekly_hours - 1) // weekly_hours
```

Tool definition-க்கு precise name, clear description, parameter schema மற்றும் return contract தேவை. General `run_anything` tool-ஐ விட narrow tool authorise, test மற்றும் observe பண்ண easy.

## State மற்றும் memory ஒன்றல்ல

**State** என்பது current run-க்கு தேவையான goal, completed steps, tool results மற்றும் remaining work. **Memory** என்பது selected information-ஐ future interactions-க்கும் carry பண்ணுவது. Useful மற்றும் permitted information மட்டும் retention rule-உடன் store பண்ணுங்க. Old memory எப்போதும் correct என்று assume பண்ணாதீங்க.

## Read tools, write tools மற்றும் approval

Approved catalogue read பண்ணுவது lower risk. Schedule modify பண்ணுவது higher risk. Read மற்றும் write capabilities-ஐ separate பண்ணி least privilege apply பண்ணுங்க. Consequential tool call-க்கு explicit approval கேளுங்க.

```python
if proposed_action.type == "schedule_activity":
    return {
        "status": "approval_required",
        "proposal": proposed_action.model_dump(),
    }
```

என்ன action நடக்கும், எங்கே நடக்கும், எந்த data use ஆகும் என்பதை UI clear-ஆ காட்ட வேண்டும். Approval கிடைத்த பிறகும் tool result-ஐ inspect செய்த பிறகு தான் success claim பண்ண வேண்டும்.

## Agent எப்போது stop ஆக வேண்டும்?

Safe agent எப்போது stop செய்ய வேண்டும் என்பதை தெரிந்திருக்க வேண்டும். Information missing, permission இல்லாமை, repeated failure அல்லது step limit வந்தால் learner-கிட்ட control-ஐ return செய்ய வேண்டும்.

Goal complete ஆனதும், required information missing ஆனதும், permission இல்லாததும், risk boundary வந்ததும், same tool repeated-ஆ fail ஆனதும் அல்லது maximum step count வந்ததும் agent stop ஆக வேண்டும்.

Tool name, safe parameters, result status, latency மற்றும் correlation ID log பண்ணுங்க. Secrets அல்லது unnecessary learner content-ஐ log பண்ணாதீங்க.

## Model Context Protocol என்றால் என்ன?

MCP என்பது AI applications exposed tools மற்றும் context-ஐ discover செய்து use பண்ண உதவும் standard. இது interoperability improve பண்ணும்; ஆனால் tool trustworthy என்று guarantee பண்ணாது. Authentication, authorisation, validation மற்றும் human approval application boundary-லேயே தேவை.

## Framework வேண்டுமா, வேண்டாமா?

Workflow small மற்றும் clear என்றால் explicit Python loop-லிருந்து start பண்ணுங்க. Durable state, branching, large tool ecosystem, tracing அல்லது team convention தேவைப்பட்டால் framework use பண்ணலாம். எந்த approach எடுத்தாலும் safety responsibility மாறாது.
