## What makes this an application

LLM-ஐ ஒருமுறை call பண்ணுவது demo. அதை real application-ஆக மாற்ற input validation, approved context, output contract, failure handling, privacy controls மற்றும் usable experience தேவை.

```text
Learner profile + approved catalogue → Python context builder → LLM → structured output → validation → response
```

இந்த flow-ல் LLM ஒரு component மட்டும். Final answer safe மற்றும் correct-ஆ இருக்கிறதா என்பதை application code decide பண்ண வேண்டும்.

## Model, instructions and context

- **System instruction:** Stable role, boundaries மற்றும் output rules.
- **User instruction:** Learner இப்போது கேட்ட request.
- **Context:** இந்த request-க்கு தேவையான verified profile மற்றும் catalogue facts.
- **Model response:** Application validate செய்ய வேண்டிய proposal.

```python
system_instruction = """
You are a learning-path assistant.
Recommend only courses present in APPROVED_COURSES.
If required learner information is missing, say so.
Return the requested structured fields.
"""
```

System instruction-ல் model என்ன role perform செய்ய வேண்டும், எந்த boundary-ஐ cross பண்ணக்கூடாது, எந்த format-ல் result கொடுக்க வேண்டும் என்பதை clear-ஆ எழுதுங்க.

## Define structured output

```python
from pydantic import BaseModel, Field

class CourseRecommendation(BaseModel):
    course_id: str
    reason: str
    prerequisite: str
    next_step: str
    confidence: float = Field(ge=0, le=1)
    missing_information: list[str]
```

Structured output use செய்தால் missing அல்லது wrong fields உடனே visible ஆகும். `course_id` approved catalogue-ல் இருக்கிறதா, prerequisite learner record-க்கு match ஆகிறதா என்பதையும் Python தனியாக verify பண்ண வேண்டும்.

## Ground the recommendation

Learner கேட்கிறார்: **SQL முடித்த பிறகு எந்த course படிக்க வேண்டும்?** Application current level, completed courses, career goal மற்றும் weekly study time-ஐ collect பண்ணும். Approved MaanavaN catalogue-லிருந்து eligible courses retrieve செய்து useful facts மட்டும் model-க்கு send பண்ணும்.

Conversation history continuity-க்கு useful. ஆனால் unlimited chat transcript அல்லது unrelated personal information-ஐ model-க்கு send பண்ணாதீங்க. தேவையான history மட்டும் select அல்லது summarise பண்ணுங்க.

## Streaming and token control

Streaming user-க்கு response fast-ஆ வருகிறது என்ற feeling கொடுக்கும். ஆனால் unvalidated JSON object-ஐ token-by-token display பண்ணாதீங்க. Structured decision என்றால் complete object வந்த பிறகு validate பண்ணி காட்டுங்க. ஒவ்வொரு request-க்கும் input/output tokens, latency மற்றும் estimated cost track பண்ணுங்க.

## Hallucination and human review

Model approved catalogue-ல் இல்லாத course-ஐ return செய்தால் Python அதை reject செய்ய வேண்டும். Confident-ஆக சொல்லப்பட்ட sentence, information correct என்பதற்கான proof இல்லை.

Model course, prerequisite அல்லது promise-ஐ invent பண்ணலாம். Unknown identifiers-ஐ deterministic checks reject செய்ய வேண்டும். Payment, enrolment, certification claim அல்லது important career decision-ஐ result affect செய்தால் human review தேவை.

## Practical build checklist

1. Learner மற்றும் response models define பண்ணுங்க.
2. Small approved course catalogue load பண்ணுங்க.
3. Relevant course facts மட்டும் select பண்ணுங்க.
4. System மற்றும் user messages build பண்ணுங்க.
5. Structured output request பண்ணுங்க.
6. Required fields மற்றும் course identity validate பண்ணுங்க.
7. Guess பண்ணுவதற்கு பதில் missing information return பண்ணுங்க.
8. Private content log பண்ணாமல் latency மற்றும் token use record பண்ணுங்க.
