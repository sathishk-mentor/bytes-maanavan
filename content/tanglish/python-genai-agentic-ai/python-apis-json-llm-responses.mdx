## API-ஐ எப்படி புரிந்துகொள்வது?

API என்பது இரண்டு applications இடையிலான contract. Client ஒரு method, URL, headers மற்றும் optional body கொண்ட request-ஐ send பண்ணும். Service status code, headers மற்றும் response body-ஐ return பண்ணும்.

| Method | பொதுவான வேலை | Example |
|---|---|---|
| `GET` | Data read பண்ண | ஒரு course retrieve பண்ணுதல் |
| `POST` | Create அல்லது run பண்ண | LLM recommendation request பண்ணுதல் |
| `PUT/PATCH` | Replace அல்லது update பண்ண | Learner progress update பண்ணுதல் |
| `DELETE` | Remove பண்ண | Approved draft delete பண்ணுதல் |

## JSON எப்படி Python data-ஆக மாறும்?

```json
{
  "course": "Python for GenAI",
  "confidence": 0.88,
  "prerequisites": ["Basic computer skills"]
}
```

JSON object Python dictionary-ஆகவும், array list-ஆகவும் மாறும். String, number, Boolean மற்றும் null values-க்கும் corresponding Python values இருக்கும்.

```python
import requests

response = requests.get(
    "https://example.com/api/courses",
    timeout=10,
)
response.raise_for_status()
courses = response.json()
```

எப்போதும் timeout set பண்ணுங்க. Timeout இல்லையென்றால் slow dependency application resources-ஐ நீண்ட நேரம் hold பண்ணலாம்.

## Response-ஐ ஏன் validate பண்ண வேண்டும்?

Status `200` வந்ததால் data correct என்று அர்த்தமில்லை. Content type, required fields, types மற்றும் allowed values எல்லாவற்றையும் check பண்ண வேண்டும்.

```python
def validate_suggestion(data: dict) -> dict:
    required = {"course", "reason", "confidence"}
    missing = required - data.keys()
    if missing:
        raise ValueError(f"Missing fields: {sorted(missing)}")
    if not 0 <= float(data["confidence"]) <= 1:
        raise ValueError("Confidence must be between 0 and 1")
    return data
```

## Failure, retry மற்றும் rate limit

Failure temporary-ஆக இருக்கும்போது மட்டும் retry useful. Invalid credentials அல்லது wrong request இருந்தால் repeated-ஆக send பண்ணாமல் root problem-ஐ correct செய்ய வேண்டும்.

Timeout மற்றும் selected `429`, `5xx` responses போன்ற temporary failures-க்கு மட்டும் retry பண்ணுங்க. Exponential backoff, jitter மற்றும் maximum attempt count use பண்ணுங்க. Async Python பல independent network calls-க்காக wait பண்ணும்போது useful; அது CPU-heavy work-ஐ automatic-ஆ faster ஆக்காது, provider limits-ஐ remove பண்ணாது.
