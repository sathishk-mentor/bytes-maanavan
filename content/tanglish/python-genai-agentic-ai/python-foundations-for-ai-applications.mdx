## Values மற்றும் data structures

```python
learner_name = "Kavin"                   # string

```

எந்த behaviour தேவையோ அதைப் பொறுத்து data structure select பண்ணுங்க. Viewer profile-க்கு dictionary சரியானது; ஒவ்வொரு preference-க்கும் meaningful key இருக்கும். Watchlist-க்கு list சரியானது; title order முக்கியம்.

## Conditions, loops மற்றும் functions

```python
def recommend_movie(age_rating: str, genre: str) -> str:
    if age_rating == "U" and genre == "Animation":
        return "Show family-friendly animation"
    return "Explore the complete movie library"

recommendation = recommend_movie("U", "Animation")
print(recommendation)
```

`if` condition ஒரு rule true-ஆ இருக்கிறதா check பண்ணும். Loop repeated items-ஐ process பண்ணும். Function ஒரு logic-ஐ name கொடுத்து reusable unit-ஆக மாற்றும். Type hints intended input மற்றும் output contract-ஐ explain செய்யும்; ஆனால் runtime-ல் எல்லா types-ஐயும் Python automatic-ஆ enforce பண்ணாது.

## Error message-ஐ evidence-ஆக படிப்பது

Code fail ஆனால் final exception line-லிருந்து start பண்ணுங்க. அதில் சொல்லப்பட்ட file மற்றும் line number-ஐ பாருங்க. Code-ஐ உடனே rewrite பண்ணாமல், smallest input use செய்து error-ஐ reproduce பண்ணுங்க.

```python
try:
    weekly_hours = int(input("Weekly study hours: "))
except ValueError:
    print("Enter a whole number, such as 5")
```

Broad `except` use செய்து எல்லா errors-ஐயும் hide பண்ணாதீங்க. புரிந்த failure-ஐ மட்டும் handle பண்ணுங்க; unexpected failure development நேரத்தில் visible-ஆ இருக்கட்டும்.

- Goal, input format மற்றும் expected examples-ஐ clear-ஆ கொடுங்க.

- Normal, empty மற்றும் invalid inputs எல்லாவற்றையும் test பண்ணுங்க.

- Dependency மற்றும் final behaviour-க்கு human ownership வைத்திருங்க.
