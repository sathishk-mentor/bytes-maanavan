## Why Python still matters in the AI era

AI code generate பண்ணினாலும், data validate பண்ண, models-ஐ call பண்ண, tools connect பண்ண, permissions enforce பண்ண மற்றும் result test பண்ண ஒரு programming language தேவை. இந்த வேலைகளுக்கு Python அதிகமாக use ஆகிறது; காரணம் அதன் syntax படிக்க easy, மேலும் API, data, machine learning மற்றும் automation-க்கு தேவையான packages கிடைக்கும்.

எல்லா Python features-ஐயும் memorise பண்ண வேண்டியதில்லை. AI workflow-ஐ power பண்ணும் code-ஐ **read, question, run, test மற்றும் improve** செய்யும் அளவுக்கு foundations strong-ஆக இருக்க வேண்டும்.

## Set up a safe workspace

## Values and data structures

```python
learner_name = "Kavin"                   # string
study_hours = 6                           # integer
is_beginner = True                        # Boolean
interests = ["Python", "AI Agents"]      # list: ordered and changeable
profile = {"goal": "AI Engineer"}        # dictionary: key and value
levels = ("beginner", "intermediate")    # tuple: fixed sequence
completed = {"SQL", "Git"}               # set: unique values
```

எந்த behaviour தேவையோ அதைப் பொறுத்து data structure select பண்ணுங்க. Learner profile-க்கு dictionary சரியானது; ஒவ்வொரு value-க்கும் meaningful key இருக்கும். Learning path-க்கு list சரியானது; course order முக்கியம்.

## Conditions, loops and functions

```python
def recommend_course(skill_level: str, interest: str) -> str:
    if skill_level == "beginner" and interest == "AI":
        return "Start with Python and Generative AI"
    return "Explore the complete course library"

recommendation = recommend_course("beginner", "AI")
print(recommendation)
```

`if` condition ஒரு rule true-ஆ இருக்கிறதா check பண்ணும். Loop repeated items-ஐ process பண்ணும். Function ஒரு logic-ஐ name கொடுத்து reusable unit-ஆக மாற்றும். Type hints intended input மற்றும் output contract-ஐ explain செய்யும்; ஆனால் runtime-ல் எல்லா types-ஐயும் Python automatic-ஆ enforce பண்ணாது.

## Read errors as evidence

Code fail ஆனால் final exception line-லிருந்து start பண்ணுங்க. அதில் சொல்லப்பட்ட file மற்றும் line number-ஐ பாருங்க. Code-ஐ உடனே rewrite பண்ணாமல், smallest input use செய்து error-ஐ reproduce பண்ணுங்க.

```python
try:
    weekly_hours = int(input("Weekly study hours: "))
except ValueError:
    print("Enter a whole number, such as 5")
```

Broad `except` use செய்து எல்லா errors-ஐயும் hide பண்ணாதீங்க. புரிந்த failure-ஐ மட்டும் handle பண்ணுங்க; unexpected failure development நேரத்தில் visible-ஆ இருக்கட்டும்.

## Use AI coding assistants responsibly

- புரியாத code-ஐ accept பண்ணுவதற்கு முன் explanation கேளுங்க.
- Goal, input format மற்றும் expected examples-ஐ clear-ஆ கொடுங்க.
- Isolated development environment-ல் code run பண்ணுங்க.
- Normal, empty மற்றும் invalid inputs எல்லாவற்றையும் test பண்ணுங்க.
- Password, API key அல்லது private learner record-ஐ paste பண்ணாதீங்க.
- Dependency மற்றும் final behaviour-க்கு human ownership வைத்திருங்க.
