## Quick Start

Meena, “Namma refund policy ChatGPT-ku epdi theriyum?”-nu kekkiraanga. General AI-ku company-oda latest document automatically theriyadhu. Adhanala answer confident-a irundhaalum correct-a irukka guarantee illai.

## Start from Basics

- **Retrieval:** Question-ku relevant-aana information-ai search pannuvadhu.
- **Chunk:** Document-oda meaningful small section.
- **Context:** Model answer panna use pannura retrieved evidence.
- **Grounded answer:** Source evidence support pannura answer.
- **Citation:** Answer endha source-lendhu vandhadhu-nu kaattura reference.

## Core Explanation

RAG-ai **open-book exam** madhiri ninaichukonga. Model memory-la irundhu guess pannaama, answer panna munnaadi correct policy page-ai search pannum. Andha evidence-ai model-kku context-a koduthu, adhai base panni answer create pannum.

## Real-World Scenario

PaisaWise support assistant refund, KYC, account access madhiri questions-ku approved policy passages-ai retrieve pannum. Answer-kooda source title and section-ai show pannina support team verify panna easy-a irukkum.

## Common Mistakes

- RAG irundha hallucination zero-nu ninaippadhu
- Wrong document-ai knowledge base-la add pannuvadhu
- Citation irundha answer kandippa correct-nu trust pannuvadhu

## Role-Based Use Cases

- **Business user:** Answer-oda source-ai verify pannuvaar.
- **Developer:** Retrieval flow and fallback-ai build pannuvaar.
- **Data or AI engineer:** Documents, index and evaluation pipeline-ai maintain pannuvaar.
- **Risk or compliance team:** Access, audit and approved-source rules-ai review pannuvaar.

## Mini Practice Task

Unga organisation-la AI answer panna vendiya oru question-ai choose pannunga. Andha answer endha approved document-la irukku-nu identify pannunga.

## Knowledge Check

1. Final answer wrong-a irundha model mattum thaan reason-aa? **Illai. Source, chunking, retrieval, prompt ellam check pannanum.**
2. Citation irundha answer automatically correct-aa? **Illai. Citation answer-ai support pannudha-nu verify pannanum.**
3. Production-ku pogum munnaadi enna venum? **Representative tests, access control, monitoring and clear ownership.**

## Key Takeaways

- RAG quality upstream documents-lendhu start aagudhu.
- Retrieval and final answer-ai separate-a evaluate pannanum.
- User-kku evidence, limitation and next action clear-a irukkanum.
