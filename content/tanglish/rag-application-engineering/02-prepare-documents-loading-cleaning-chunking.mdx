## Start from Basics

- **Retrieval:** Question-ku relevant-aana information-ai search pannuvadhu.
- **Chunk:** Document-oda meaningful small section.
- **Context:** Model answer panna use pannura retrieved evidence.
- **Grounded answer:** Source evidence support pannura answer.
- **Citation:** Answer endha source-lendhu vandhadhu-nu kaattura reference.

## Core Explanation

Oru periya filing cabinet-la aayirakkanakkaana pages irukku-nu ninaichukonga. RAG system documents-ai clean panni, meaningful chunks-a divide panni, search panna ready-a store pannum. Question varumbodhu correct pieces-ai mattum eduthu model-kku kodukkum.

## Components and Decisions

Romba small chunk context-ai lose pannalaam. Romba large chunk irrelevant text-ai kondu varalaam. Heading, paragraph, table boundary madhiri natural structure-ai respect pannura balanced chunks usually better starting point.

## Real-World Scenario

PaisaWise support assistant refund, KYC, account access madhiri questions-ku approved policy passages-ai retrieve pannum. Answer-kooda source title and section-ai show pannina support team verify panna easy-a irukkum.

## Common Mistakes

- PDF extract correct-a irukka check pannaama index pannuvadhu
- One magic chunk size ellaa documents-kum use pannuvadhu
- Source, date, permission metadata-ai skip pannuvadhu

## Knowledge Check

1. Final answer wrong-a irundha model mattum thaan reason-aa? **Illai. Source, chunking, retrieval, prompt ellam check pannanum.**
2. Citation irundha answer automatically correct-aa? **Illai. Citation answer-ai support pannudha-nu verify pannanum.**
3. Production-ku pogum munnaadi enna venum? **Representative tests, access control, monitoring and clear ownership.**

## Key Takeaways

- RAG quality upstream documents-lendhu start aagudhu.
- Retrieval and final answer-ai separate-a evaluate pannanum.
- User-kku evidence, limitation and next action clear-a irukkanum.
