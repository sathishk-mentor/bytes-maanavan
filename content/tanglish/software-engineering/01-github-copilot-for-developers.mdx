## 60 seconds-ல் GitHub Copilot

GitHub Copilot என்பது developer work-ஐ assist செய்யும் AI coding tool. அது current file, selected code, open files, repository instructions மற்றும் user prompt போன்ற context use செய்து code suggestion, explanation, test, plan அல்லது multi-file change prepare பண்ணலாம்.

Copilot output proposal மட்டுமே. Requirement correct-ஆ புரிந்ததா, code repository pattern-க்கு match ஆகிறதா, tests pass ஆகிறதா, security மற்றும் performance safe-ஆ இருக்கிறதா என்பதை developer verify பண்ண வேண்டும்.

## One product, multiple interaction patterns

| Pattern | Best use | Human role |
|---|---|---|
| Inline completion | Small predictable code continuation | Suggestion inspect மற்றும் accept/edit |
| Chat | Explain, compare, debug | Context கொடுத்து answer challenge பண்ணுதல் |
| Edit | Selected files-ல் bounded change | Scope மற்றும் diff review பண்ணுதல் |
| Agent mode | Multi-step repository task | Plan, permissions, commands மற்றும் result supervise பண்ணுதல் |

Small task-க்கு smallest suitable mode use பண்ணுவது clarity மற்றும் reviewability improve பண்ணும்.

## எந்த capability-ஐ எப்போது choose பண்ணுவது?

Boilerplate அல்லது familiar pattern-க்கு completion. “இந்த function ஏன் fail ஆகிறது?” போன்ற questions-க்கு chat. Two or three known files-ல் controlled change-க்கு edit. Clear acceptance criteria கொண்ட multi-step repository task-க்கு agent mode. Unclear requirement இருந்தால் முதலில் மனிதர் problem-ஐ clarify பண்ண வேண்டும்.

## Try பண்ண வேண்டிய exploration prompt

<PromptBox label="Repository-ஐ புரிந்துகொள்ள Copilot prompt">

Explain how this feature works using only the files I have provided. Identify the entry point, data flow, validation, external dependencies and tests. Separate confirmed evidence from assumptions. Do not modify files.

## Common mistakes

<Mistakes>

- Autocomplete fast-ஆ வந்ததால் correct என்று accept பண்ணுவது.
- Relevant file/context கொடுக்காமல் repository-specific answer expect பண்ணுவது.
- Large agent change-ஐ plan அல்லது checkpoints இல்லாமல் run பண்ணுவது.
- Generated dependency, command மற்றும் migration-ஐ inspect பண்ணாமல் execute பண்ணுவது.
- Tests pass ஆனாலும் business requirement satisfy ஆனதா check பண்ணாமல் விடுவது.

</Mistakes>

## Interview-ல் எப்படி explain பண்ணுவது?

<ThemeCard title="Copilot-ஐ எப்படி responsibly use பண்ணுவீங்க?" badge="CAREER">

Task-க்கு smallest suitable mode choose செய்து relevant context மற்றும் acceptance checks கொடுப்பேன். Generated diff-ஐ inspect செய்து tests, security checks மற்றும் repository conventions மூலம் verify பண்ணுவேன். AI speed கொடுக்கலாம்; final engineering decision என்னுடைய responsibility.

</ThemeCard>

## நினைவில் வைக்க வேண்டிய key points

<Takeaways>

- Copilot code completion-ஐ விட பல interaction patterns கொடுக்கும்.
- Better context better repository-fit output கொடுக்கும்.
- Small, reviewable changes large generated changes-ஐ விட safer.
- Tests evidence கொடுக்கும்; human judgment requirement மற்றும் risk-ஐ evaluate பண்ணும்.
- AI assist பண்ணும்; developer accountability transfer ஆகாது.

</Takeaways>
