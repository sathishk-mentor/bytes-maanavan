## Copilot vs Developer Responsibility
| Decision | Copilot help | Developer responsibility |
|---|---|---|
| Boilerplate | Draft fast-a create pannum | Project convention verify pannum |
| Business rule | Pattern suggest pannum | Actual rule and edge case confirm pannum |
| Testing | Test cases propose pannum | Coverage meaningful-a irukka check pannum |
| Security | Safer pattern suggest pannalaam | Access, secrets, dependency risk review pannum |
