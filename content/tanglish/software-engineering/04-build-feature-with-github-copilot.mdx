## Supervised Feature Journey
1. Requirement and prohibited changes-ai define pannunga.
2. Agent plan-ai files and steps level-la review pannunga.

## Safe vs Unsafe Autonomy
| Safer boundary | Risky boundary |
|---|---|
| Named files and commands | Entire repository unrestricted |
| Read and test automatically | Deploy/delete automatically |
| Payment change-ku approval | Model confident-na proceed |
| Final diff summary | Hidden multi-file edits |

## Safe Boundary
Specific files, allowed changes, prohibited changes, required tests, final summary ellam task-la mention pannunga.

## Common Mistakes
Unlimited scope; terminal commands inspect pannaama allow pannradhu; final diff review pannaama merge pannradhu.
