## Priya-வின் AI assistant-க்கு guess வேண்டாம், facts வேண்டும்

Priya, **“Active-ஆ இருக்கும் இரண்டு headphones-ஐ highest price first காட்டு”** என்று கேட்கிறார். Language model கேள்வியைப் புரிந்துகொள்ளும். ஆனால் current product name, status, price எல்லாம் database-ல் இருக்கும். சரியான rows-ஐ controlled-ஆ retrieve செய்ய SQL பயன்படும்.

## Tables business data-க்கு தெளிவான structure கொடுக்கும்

| Table | ஒரு row எதைக் குறிக்கும்? | முக்கிய columns |
|---|---|---|
| `products` | ஒரு product | `product_id`, `name`, `category`, `price`, `status` |
| `customers` | ஒரு customer | `customer_id`, `name`, `city` |
| `orders` | ஒரு order | `order_id`, `customer_id`, `ordered_at`, `total_amount` |

**Primary key** ஒரு row-ஐ unique-ஆ identify செய்யும். **Foreign key** மற்றொரு table-ல் இருக்கும் related row-உடன் connect செய்யும்.

## Database request-ஐ எப்படி answer செய்கிறது?

1. `FROM` எந்த table என்று தேர்வு செய்கிறது.
2. `WHERE` தேவையான rows மட்டும் filter செய்கிறது.
3. `SELECT` வேண்டிய columns மட்டும் return செய்கிறது.
4. `ORDER BY` result order-ஐ நிர்ணயிக்கிறது.
5. `LIMIT` response size-ஐ கட்டுப்படுத்துகிறது.

## SQL-ஐ step by step படிப்போம்

```sql
SELECT product_id, name, price
FROM products
WHERE category = 'Headphones'
  AND status = 'ACTIVE'
ORDER BY price DESC
LIMIT 2;
```

| product_id | name | price |
|---:|---|---:|
| 101 | Wireless Headphones | ₹4,999 |
| 104 | Studio Headphones | ₹3,499 |

Application query-ல் `SELECT *` avoid செய்யுங்கள். Explicit columns பயன்படுத்தினால் data transfer குறையும்; future schema change sensitive data-ஐ accidental-ஆ expose செய்யாது.

## Customer மற்றும் order-ஐ connect செய்வது

```sql
SELECT o.order_id, c.name, o.total_amount
FROM orders AS o
JOIN customers AS c ON c.customer_id = o.customer_id
WHERE o.ordered_at >= DATE '2026-09-01'
ORDER BY o.ordered_at DESC;
```

`JOIN` stable ID மூலமாக related rows-ஐ connect செய்கிறது. Name மூலம் join செய்தால் duplicate names காரணமாக wrong result வரலாம்.

## பொதுவான mistakes

<Mistakes>

- தேவையில்லாமல் `SELECT *` பயன்படுத்துவது.
- `= NULL` எழுதுவது; சரியான syntax `IS NULL`.
- “latest” query-ல் `ORDER BY` இல்லாமல் `LIMIT` பயன்படுத்துவது.
- Stable ID-க்கு பதிலாக name மூலம் join செய்வது.
- User text-ஐ SQL string-உடன் concatenate செய்வது.

</Mistakes>
