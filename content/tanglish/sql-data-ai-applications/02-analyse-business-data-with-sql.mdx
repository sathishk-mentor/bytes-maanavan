## GROUP BY detail level-ஐ மாற்றும்

```sql
SELECT customer_id, COUNT(*) AS order_count,
       SUM(total_amount) AS total_spend
FROM orders
WHERE status = 'PAID'
GROUP BY customer_id;
```

Grouping-க்கு முன்பு ஒரு row என்பது ஒரு order. Grouping-க்கு பிறகு ஒரு row என்பது ஒரு customer summary.

## Window function rows-ஐ மறைக்காமல் context சேர்க்கும்

<SQLWindowLab />

```sql
WITH customer_spend AS (
  SELECT c.customer_id, c.name,
         SUM(o.total_amount) AS total_spend
  FROM customers AS c
  JOIN orders AS o ON o.customer_id = c.customer_id
  WHERE o.status = 'PAID'
  GROUP BY c.customer_id, c.name
)
SELECT customer_id, name, total_spend,
       RANK() OVER (ORDER BY total_spend DESC) AS spend_rank
FROM customer_spend
ORDER BY spend_rank, customer_id
LIMIT 10;
```

Customer ID மற்றும் name இரண்டையும் group செய்தால் same name கொண்ட இரண்டு customers merge ஆகமாட்டார்கள். Final `ORDER BY` தான் top-ten display order-ஐ guarantee செய்கிறது.

| customer_id | name | total_spend | spend_rank |

| C101 | Meena | ₹12,000 | 1 |
| C103 | Arun | ₹9,500 | 2 |
| C102 | Farah | ₹7,200 | 3 |

## Running total எப்படி உருவாகிறது?

```sql
SELECT order_day, daily_revenue,
       SUM(daily_revenue) OVER (
         ORDER BY order_day
         ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
       ) AS running_revenue
FROM daily_sales
ORDER BY order_day;
```

Window frame எந்த rows calculation-ல் சேர வேண்டும் என்பதை explicit-ஆ கூறுகிறது.

<Scenario title="Practical scenario: retention dashboard">

Subscription team monthly totals-ஐ `GROUP BY` மூலம் உருவாக்கி, `LAG()` மூலம் previous month-உடன் compare செய்யலாம். ஒவ்வொரு month row-வும் visible-ஆ இருக்கும்.

</Scenario>

## பொதுவான mistakes

<Mistakes>

- Group definition இல்லாமல் row columns மற்றும் aggregates mix செய்வது.
- Unique அல்லாத customer name மட்டும் group செய்வது.
- Window function எப்போதும் `GROUP BY`-ஐ replace செய்கிறது என்று நினைப்பது.
- Final sorting இல்லாமல் `LIMIT` பயன்படுத்துவது.
- Window frame-ஐ கவனிக்காமல் moving calculation செய்வது.

</Mistakes>

## Interview-ல் எப்படி explain செய்வது?

<ThemeCard title="GROUP BY vs window function" badge="CLEAR ANSWER">

GROUP BY detail rows-ஐ one-row-per-group summary-ஆக collapse செய்கிறது. Window function current rows-ஐ retain செய்து comparison அல்லது rank சேர்க்கிறது.

</ThemeCard>

## Beginner FAQ

**RANK, DENSE_RANK, ROW_NUMBER எப்படி தேர்வு செய்வது?** Unique sequence-க்கு ROW_NUMBER, tie மற்றும் gap-க்கு RANK, tie ஆனால் gap இல்லாமல் இருக்க DENSE_RANK.
